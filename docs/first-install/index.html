First-install walkthrough

From downloading cr-clothes to installing your first exported design, one screen at a time.

The ten screens

Pick a screen to show it in the player.

  1. First install

    From download to installing your first exported design.

    You need a recent FiveM server artifact, a clothing pack you own, and the Cfx.re “Stream Custom Clothing” entitlement on your server key.

  2. 1 Download

    On the GitHub page press Code, then Download ZIP. Unzip it.

  3. 2 Drop it in

    Copy the cr-clothes folder into your server’s resources folder. That one folder is the whole install.

    Only cr-clothes goes on the server. The bot is optional and the docs are for you.

  4. 3 Add these lines to server.cfg

    The webhook is where finished packs are announced. The public address is the one players connect to.

    ensure cr-clothes
add_ace group.admin command.clothbuilder allow
add_ace group.admin crclothes.admin allow

set clothdesigner_webhook_url "https://discord.com/api/webhooks/..."
set clothdesigner_public_url  "http://YOUR.SERVER.IP:PORT"

  5. 4 Start the server

    One line tells you it is running. Then run clothwebhook_test in the console and open the link it posts in Discord.

  6. 5 Add your clothing

    Copy a clothing pack you own into cr-clothes/garments and run crclothes_prepare, then refresh and restart cr-clothes. The pack itself stays installed with its own ensure line.

    Hosted server? crclothes_prepare makes a zip instead. clothbake_get prints its link; upload its generated folder into cr-clothes.

  7. 6 Design in game

    Type /clothdesigner, double-click your garment and design on it. The 3D preview updates as you work. Then press Export clothing pack.

  8. 7 The link lands in your Discord

    A message with the 3D preview and a download link back to your own server. The pack itself never leaves it. Download it before you restart.

  9. 8 Install the pack

    Unzip it and put the pack folder into resources. Add its ensure line below your other clothing packs, restart the server, and join again.

    New-item packs are new in 1.1.0 and not yet tested in the game: try one on a test server first. Each installed pack uses one of a few clothing collection slots, so install a few designs, not dozens.

  10. 9 Wear it

    The pack is built to add your design as a new clothing item. New in 1.1.0 and not yet tested in the game: try one on a test server first.

Delivery options, permissions, hosted servers, troubleshooting and the known limits are in the admin guide.
